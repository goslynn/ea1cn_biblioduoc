Access token

Se manda el ACCESS token y no el id token: el id token dice quien eres, pero no lleva el claim scope, y el metodo de API Gateway lo exige. Con un id token la respuesta seria 401.

Payload decodificado

Fijate en token_use, client_id y sobre todo en scope. Se decodifica en el navegador solo para mirarlo: la firma la verifican API Gateway y Spring, cada uno por su cuenta.
